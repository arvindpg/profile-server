# Frontend

## Honest Assessment

Frontend isn't my primary focus - I'm stronger on backend and infrastructure. But I can build functional UIs when needed and collaborate effectively with frontend specialists.

## Technologies I've Used

| Technology | Experience | Context |
|------------|------------|---------|
| **React.js** | Intermediate | Security dashboards, admin panels |
| **AngularJS** | Legacy | Maintained older applications |

## What I've Built

### Security Dashboards
At FireCompass, I delivered security dashboards using React.js to display scan results and CVE data in real-time. These dashboards help security teams make decisions about which vulnerabilities to prioritize. The work involved building APIs on the backend and creating the visualization layer on the frontend.

### Authentication & Access Control UIs
In my previous company, I worked on frontend features for the authentication, authorization, and user management modules. I led the migration from Role-Based Access Control to Claims-Based Access Control, which involved both backend changes and updating the frontend to reflect the new permission model.

### Admin Panels
I've built various admin interfaces for internal tools - nothing fancy, but functional interfaces that get the job done. My philosophy is that internal tools don't need to be beautiful, but they do need to be clear and usable.

## What I Prefer

Given the choice, I'd rather work on backend systems, APIs, and infrastructure. But I understand that being able to build end-to-end features - including the frontend - makes me more effective as an engineer. I can pick up frontend work when the team needs it.
